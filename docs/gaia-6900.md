# quietfan on a Check Point 6900 (Gaia)

For a **Check Point 6900** (QM-20-00) running **Gaia R80.40** (Python 2.7, SysV `chkconfig`).

This is **not** the 16200 path. The Super I/O is an **NCT6779** (`nct6775` driver), not an NCT7904.

16200 Gaia is in [gaia.md](gaia.md). Shared safety notes are in the [root README](../README.md).

## What it does

BIOS SmartFan IV keeps PWM 130 (~11k RPM) even at 30–45°C, because the lowest table point is **50°C → PWM 130**.

The daemon:

- Reads `temp7_input` (PECI Agent 0 / Gaia `CPU PECI Temp`) and `temp2_input` (CPUTIN / Gaia `CPU Temp`)
- Maps the hottest onto the 6900 curve (idle **PWM 20**)
- Writes `pwmN_enable=1` and `pwmN` for channels **1–4**
- Loops every 4s with 2°C down-hysteresis
- Re-applies PWM every loop so SmartFan does not steal the channels back

**PWM5** has no tach (`fan5=0`). Leave it alone. There are **no PSU fan tachs** on this box (Gaia PSU is Up/Down only; IPMI has no PSU watt/fan SDRs).

## Hardware

Intel Core i9-9900KF. Chip is `nct6779` at `/sys/devices/platform/nct6775.2608`.

```text
/sys/devices/platform/nct6775.2608/
  temp2_input     CPUTIN (Gaia CPU Temp)
  temp7_input     PECI Agent 0 (Gaia CPU PECI Temp) — what BIOS SmartFan tracks
  pwmN            duty 0–255
  pwmN_enable     1 = manual, 5 = SmartFan IV
  fan1..fan4      chassis RPM
```

`pwmN_enable`: **1** = manual, **5** = SmartFan IV. The daemon writes `1`, then the duty.

BIOS SmartFan IV table (all four chassis fans, temp select = PECI Agent 0):

| Point | Temp | PWM |
|-------|------|-----|
| 1 | 50°C | 130 |
| 2 | 55°C | 140 |
| 3 | 60°C | 150 |
| 4 | 65°C | 200 |
| 5 | 70°C | 255 |

Start PWM 96, floor 0. Measured: PWM 25 ≈ 2170 RPM, PWM 20 ≈ 1740 RPM, PWM 16 ≈ 1300 RPM (below Gaia’s 1480 RPM alarm). Idle stays at **20**.

IPMI `SYS_FAN1`–`4` exist but read `No Reading` while `nct6775` owns the Super I/O. Same BMC-blind pattern as the 16200, different chip.

Do **not** unbind `nct6775` or talk raw I2C to the Super I/O while the driver is bound.

## Files on the appliance

| Path | Role |
|------|------|
| `/usr/local/sbin/quietfan` | Python 2.7 daemon (`gaia/quietfan-qm20`) |
| `/etc/rc.d/init.d/quietfan` | SysV init (`gaia/quietfan-qm20.init`) |
| `/var/run/quietfan.pid` | PID file |
| `/var/log/quietfan.log` | stdout/stderr (`python -u`) |
| `/etc/rc.local` | Extra `quietfan start` at end of boot |

## Install

Expert mode. Python 2.7 is already there.

```bash
cp gaia/quietfan-qm20 /usr/local/sbin/quietfan
cp gaia/quietfan-qm20.init /etc/rc.d/init.d/quietfan
chmod 755 /usr/local/sbin/quietfan /etc/rc.d/init.d/quietfan
python -m py_compile /usr/local/sbin/quietfan
chkconfig --add quietfan
chkconfig --list quietfan
grep -q quietfan /etc/rc.local || echo '/etc/init.d/quietfan start' >> /etc/rc.local
/etc/init.d/quietfan start
```

You want `2:on 3:on 4:on 5:on`.

## Verify

```bash
ps -ef | grep quietfan | grep -v grep
H=/sys/devices/platform/nct6775.2608
cat $H/pwm1 $H/pwm1_enable $H/fan1_input $H/temp7_input
tail /var/log/quietfan.log
```

Log:

```text
quietfan: temp=44.0C pwm=20
```

## Hand control back to SmartFan (loud)

```bash
/etc/init.d/quietfan stop
H=/sys/devices/platform/nct6775.2608
for i in 1 2 3 4; do echo 5 > $H/pwm${i}_enable; done
```
